## Parent acceptance and separate author inspection

All five acceptance entries in active-package.json are passed. Schema 2 adds
recovery metadata; the exact historical schema 1 remains supported without a
writer. SQLite API snapshots retain committed WAL, accepted evidence, operation
bindings/outcomes and retained redaction state. Backups are exclusive, validated
and flushed (including the parent directory on POSIX) before schema DDL. The
upgrade receipt and version change share one transaction. Injected failure and
actual process exit before commit preserve schema 1; current stores remain schema
2. Restore never overwrites an existing sandbox. No automatic reset occurs.

Explicit compatible model migration is separate from ordinary editing. Native
migration records a new revision, parent/fork lineage, evidence and deduplicated
outcome in one transaction; it never moves the original branch. Imported migration
records archive/revision origin atomically in a separately selected sandbox and
preserves projected identities/redactions. Completed native/import outcomes are
recovered before consulting the current model registry. Absent mechanism code is
not supplied by imports; readable historical data does not grant execution.

Cold historical discovery and bounded tables work independently of numerical
handshake and prior UI caches. Exact schemas, query-only SQLite, disabled trusted
schema/extensions, work/byte deadlines and the existing archive validator protect
these paths. Original historical evidence is distinguished from privacy-projected
archive evidence and newly computed comparison results. Missing/reduced evidence
is unavailable; no recomputation fills gaps. Unsupported schemas, corrupt database
and corrupt archive failures give bounded preservation guidance without paths.

The main-owned recovery API serializes launches, owns all dialogs, binds selected
contexts and derives repeatable migration IDs across restart. Renderer/preload
expose one named typed endpoint with no paths or raw database access. The UI has
keyboard controls and text tables; save errors label previews as unsaved in the
view until confirmation. Existing engine restart, bounded shutdown, stale-apply
and uncertain-operation paths remain covered by the integrated suites.

Separate author inspection found and corrected backup directory durability,
pre-registry migration replay, exact native source-path selection, archive
provenance atomicity, unknown mechanism rejection and native versus projected
historical labels. This is **solo-validated; agent review deferred**, not an
independent or scientific review. The new package adds 21 engine cases, 2 desktop
unit cases and 1 packaged scenario; cumulative pass counts are not new features.
