## Scope and acceptance

One explicitly selected production stage precedes the existing freight/storage/use
chain. Each production claim names the actual canonical extraction account and
one dated finite sink allowance already present in the same initial work/chain
book. Unique resource/role mappings and canonical access references are required.
The environment adapter composes access restrictions with actual production
choices, then the shared allocator jointly constrains extraction, operating inputs,
yields and sink budgets. Earlier work claims are closed. The actual production
result supplies downstream stages; extraction is never debited a second time.
No probe book, separately allocated stock pool or slot/kg approximation supplies
the candidate. Validation may evaluate a detached candidate, which is discarded.

Every residual output plus explicit loss has an exact mass-equivalent sink
requirement, checked with Fraction and explicit unit scales. Product and residual
stocks retain the existing transformation conservation identity. Sink allowance
use is a budget debit, not another physical mass debit or proof of disposal or
absorption. Hypothetical coefficients are supplied by the host; no reviewed
scientific model is implied. Positive residual/loss and one sink mapping per claim
are required in this bounded child. Multiple production stages, resource mixtures,
zero-residual processes and downstream ecological processing remain unimplemented.

Unknown extraction/sink knowledge, access or operating terms withhold the complete
candidate. Known denied access blocks new extraction while preserving independent
work and prior postings. All production competitors share one queue and book.
Previously retained debits, reservations, subtotals and imports remain exactly
once. Selected ecological limits diagnose gross outward postings, including prior
unclaimed debits, without implicitly enforcing policy or netting away imports.
Joint shortfalls are labeled coupled input shortfalls rather than attributed to
extraction alone. Exact coefficients and permission causes remain in evidence.

Reject omitted/duplicate/foreign mappings, wrong resource/account roles, dates,
units, residual rates, replenishment of extraction stocks and downstream boundary
spending. Private host callbacks snapshot requests; opaque evidence digests grant
no book/write authority. Explicit declaration reviews, world/request/runtime
bindings and repeated common conformance remain required.

regressions; generated contracts/content, TypeScript/desktop/roadmap, readiness,
