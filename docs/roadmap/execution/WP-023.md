## Implementation and separate author inspection

The Python comparison schema generates reusable history, quantity-comparison,
private-rationale and branch-action DTOs. Main/preload expose four named calls,
validate schemas and selected-context/store/civilization grants, and bind replies
structurally. Mutation operation IDs are main-owned and retained for identical
retries after uncertain replies. Stale branch sequences fail transactionally.
No SQL, paths, callback, arbitrary IPC or executable content is renderer-controlled.

Lineage reads all retained civilization futures in acceptance order, ten rows
and 800,000 item bytes per page. Archived original option wording and selected
choices remain readable. Rationale references remain in immutable lineage;
separately classified rationale text requires an explicit selected-revision read,
is context-validated, is not put in React Query or immutable evidence, and can be
hidden. Missing/redacted/deleted private payloads stay visibly unavailable.
Comparison pages contain at most ten combined outcome/change rows under the same
item-byte bound. A single oversized archive/comparison item fails visibly and
requires future chunking; no archived wording is silently truncated.

Undo/redo, branch rename, historical fork and restore use existing transaction,
operation replay and stale-sequence checks. Applying after undo creates a named
retained-future head before clearing redo. Restore similarly preserves the old
future; revisions and decision archives are never rewritten. Historical inspection
is labeled separately from the active branch head. Forking/restoring a historical
revision requires an explicit target while operating on the selected branch head.

Comparisons read only accepted data with no executable model requirement. Values
are aligned conservatively by stable indicator identity, definition version/name,
procedure and inputs, unit/scope/aggregation/time/denominator, world/catalog/model/
numerical-runtime versions and exact saved executable-model digest. Effective
times must match. Known numerical values use the shared Decimal/Fraction-checked
subtraction; unsupported precision returns a reason instead of a rounded delta.
The result names retained versus unavailable evidence on both sides, independently
of complete/incomplete/unavailable explanatory closure. No conversion, aggregation,
ranking, score, recomputation or scientific adequacy claim is inferred.

Changed values/commitments, assumptions, policies, goals and reference metadata
are paged alongside results. Exact accessible tables and keyboard actions preserve
scope, units, time and context. Player private text is inert React text.

The separate author pass checked transactional retained futures, target and branch
bindings, operation replay after lost replies, private-payload context and cache
isolation, original wording, page byte bounds, compatibility and unknown semantics.
It corrected precision-loss subtraction, byte-based lineage paging, and a mutation
reply dependency on a subsequent catalogue read. This remains author inspection,
not independent agent review.
