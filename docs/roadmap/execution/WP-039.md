## Implementation and separate author inspection

Format/fixture scope was fixed before archive and dialog consumers. A later pinned
accepted synthetic fixture supplements real-provider and adversarial tests.
The engine exports typed historical projections and full accepted evidence closures,
not raw SQLite tables or arbitrary files. Default exports remove private descriptors,
notes/rationale references and all original private-dependent revision/branch hashes;
all nested alternatives and snapshots share the projection policy. Physically used
assumption parameters retain redacted descriptor references. Random declaration
references preserve their shape with an explicit redacted probability reference
where required. Fork declarations bind projected parent random plans. No stochastic
sampler or numerical registry is invoked for imported historical inspection.

Main owns file dialogs and a named, typed archive endpoint. Archive bytes stay in
the engine; the renderer receives summaries and bounded text table pages. The
archive view is available in an empty selected sandbox, supports cold list/read,
and labels imported histories as historical projections requiring explicit
migration before editing. Optional private note/rationale payloads honor active
deletions; no transcript/attachment store exists in this product version. Import
uses one transaction with immutable content blobs. Identical imports replay;
distinct projections coexist. Exclusive publication of a complete fsynced temporary
file preserves prior export destinations. Imported collections can be re-exported,
further redacted or evidence-reduced; missing evidence cannot be conjured back.

Separate author inspection followed all historical alternatives, nested evidence
snapshots and reference closure; ZIP headers/types/path/hash/budget validation;
snapshot/evidence binding; data-only model/graph readability; fork/draw identities;
transactional write failures and real process exit; dialog grants and renderer
paging/escaping. It caught and corrected random references being confused with
private metadata, mandatory probability-assumption redaction, fork parent digest
rebinding, retained-future branch IDs containing private-dependent hashes, and complete
transition allocation/ownership evidence needing explicit retention.
Focused regressions cover each. Early full runs were superseded when inspection fixes changed the candidate;
they are not claimed as verified final full runs. The final full candidate is validated below. Author inspection is not
independent or scientific review.

Imports intentionally create immutable historical collections, separate from
native editable revision catalogues. Original operation retry journals are not
portable and projected identities cannot authorize edits. Explicit editable model
migration and backup/restore acceptance remain WP-041. This is the safe-readable
archive workflow, not a G5/M5 claim; WP-040 reports and WP-041 recovery remain open.
Linux packaged validation is exercised here; Windows x64 is unrun. No Mac target,
source-model activation, scientific acceptance or merge authorization is implied.
