## Integration semantics and limits

The new host composes typed canonical requests; it never loads code named by
content. Every scarce account shared between invocations must carry the identical
complete procedure: openings, claims, postings, reservations, queue and holders.
A second account name cannot create another time budget for the same cohort and
period. Shared work is counted once. Provisioning continues from the exact
allocated work snapshot and closes earlier claims before its selected use phase.
Other finite books remain disjoint and retain independent commitments.

An explicit authored requirement names an actual source result, target result,
canonical shared references and a condition/provenance reference. These are
hypothetical arrangement prerequisites, not universal relationships inferred from
co-presence. Local capacity results and integrated readiness remain separate.
Known denial blocks only the declared dependent use; unknowns remain unresolved.
No requirement grants rights, overrides voluntary participation, creates a service,
or transfers quantities between unrelated slot dimensions. Institutional context
links are declared separately from numerical dependency edges. Host evidence
ports carry context-bound validation evidence, not social-effect magnitudes.

Allocators issue posting IDs local to their own books. The combined private
snapshot uses stable pool-qualified IDs and retains every original ID and its
account footprint in `posting_origins`; original native reports are unchanged.
The shared account engine checks that detached snapshot. The private ledger
adapter closes already-staged claims, so acceptance through the ordinary revision
service does not allocate them a second time. Explicit reviews are still required
before trusted callbacks activate. Bound conformance reconstructs the actual case
world and rejects altered requests, identities, context, versions and snapshots.

Independent Fraction balances cover every account and prior care fulfillment;
protected learning reservations survive. A second differently named time book,
forged source evidence, unknown/denied prerequisites, foreign periods/scopes,
substituted references and missing reviews are rejected or remain unresolved as
appropriate. No overall civilization score or automatic winner is introduced.

All results remain partial and hypothetical. Education capacity is not learning;
health inputs are not treatment; communication slots are not delivered or true
messages; voluntary accommodation is not attendance or belief; continuity slots
are not rescue or a hazard model. Operating resources, endogenous transitions,
source scientific validity and other absent effects remain visible in the fixture
and retained domain reports. Environmental selected limits remain separate
native diagnostics, rather than being silently translated into physical supply.
The source inventories remain `not_activated`. Numerical source-choice activation,
source-model validation and native Windows certification are not claimed.
