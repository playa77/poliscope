geographic overlap; membership uses explicit cohort relationships and declared
aggregation; authority is jurisdiction/ownership/obligation; networks expose
connectivity/access/supply/consumption/information relationships. No hierarchy is
used to infer membership or authority. Overlapping authorities reference one asset.
The default table shows the civilization's declared relationships and selected-
scope values/accounts, with explicit identity filtering for neighboring records.

lists and diagrams bounded. The diagram describes the current table page;
seed/positions exist only in React and are absent from all mutation contracts.

public declared obligation terms and player-owned existing condition values use
pure Preview and explicit Apply. Existing relationship kind/endpoints retain
canonical identity; a changed counterparty requires a new relationship identity.
Public obligation terms are labeled design content, not fulfilled resource flows.

and area validation remains nonnegative, with integral population. Unknown values
remain unknown until answered through the existing interview starting-condition
workflow. New cohorts require an explicit fixed-input/dynamic-state/solved-capacity role;
existing population roles cannot be rebound through topology edits. No arbitrary
input graph or executable code is accepted through IPC.
Completed apply operations replay before stale-head rejection; retries retain a
main-owned operation identity. Historical edits require a fork.

condition/account readers. Unscoped canonical edges remain visibly unmapped,
not assigned invented scopes/domains. World, domain starting conditions, matrix
