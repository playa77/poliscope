## Implementation and separate author inspection

Both children and parent behavior are implemented. The renderer selects a local
sandbox folder through main's native chooser. Main stops the bootstrap child before
using a bounded, serialized one-shot production Python workspace service; historical
reader/reconnect transitions revoke workspace grants. Thirty-two queued calls,
16 KiB requests, 1 MiB replies, 25-row world pages and a 1,000-branch/1 MiB catalogue
bound resource use. Branch discovery selects only latest immutable journal records;
it does not cap retained history or enumerate caches/private payloads. Store schema
1 and dependency locks remain unchanged. Existing application-data-directory
single-instance ownership and SQLite transaction serialization remain in force.

Main validates caller, arity, exact generated schemas, selected-store/civilization/
branch/revision grants, model/time/scope/collection response bindings, safe numeric
tokens and private-error projection. Creation IDs come from main, with the same
request/operation retained for uncertain same-session retries. Reopening the folder
lists confirmed worlds after process loss; creation is never inferred from a
renderer cache. Public preview/apply or arbitrary store/path grants are not added.

The Python-owned starting model intentionally has no numerical mechanisms. Empty
mechanism graphs are now structurally valid so an unanswered sandbox need not
receive an injected policy. Blank population/land stay typed unknowns; entered
quantities pass exact Decimal/nonnegative and integral-population validation. The
explicit synthetic reference offers editable conditions only, with no civic design
or goals. Optional purpose remains session-local and never becomes a goal or saved
simulation input. Existing saved models can be inspected without model execution.

One React selection owns civilization/branch/revision/scope/model/time. TanStack
keys include the entire context, version identities, scope and view; cancelled or
late old-state responses cannot replace current-state results. Scope directories
and scoped values come from paginated production reads. Keyboard-accessible rail,
all twelve specification domains, state labels and optional inspector remain usable
with unanswered choices. Retained revisions display read-only historical labels.
