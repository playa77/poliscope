## Implementation and separate author inspection

The Evidence and models workspace reuses the retained result/trace inspectors,
archived source reader and mechanism/rule reader. It lists versioned model
records, retained declarative operator graphs, source descriptors/licenses,
assumption definitions, uncertainty forms and explicit unsupported status.
New source-backed commitments retain the source descriptors used by their
original alternatives. Excerpt reads reject a bundle with a different retained
source descriptor; a missing archive is unavailable rather than substituted.
Trusted Python implementation identities are inspectable declarations, not
embedded executable source. Existing legacy source choices without a descriptor
remain legacy catalog references; no historical excerpt completeness is inferred.

Assumption edits require an existing public, player-owned point definition,
selected scope, an actual bound input and matching value type/unit/period/
denominator. Range/distribution/qualitative inputs are read only. Normal pure
Preview and explicit revision Apply retain stale checks and host-owned replay
identities. Execution requires the matching trusted model/runtime; unmodeled
workspaces do not gain numerical social models. Python fixtures validate a
real finite allocation change from 60 to 20 kg under a changed bound assumption.

Goals start empty and use existing typed observation semantics. Their scope
mapping lives beside revision metadata, preserving old measurement/evidence
schemas and historical report digests. Narrative questions and comparison
thresholds are explicitly disclosed as ordinary immutable goal content.
Goal/annotation edits assert unchanged physical result identity. Supported
assumption edits remain separate from goals and private notes. Branch comparison
uses the existing retained comparison service, with no winner ranking.

Inquiry, expectation, observation, gap and proposal text live in classified
`private-notes/` payloads. Revision inputs, alternatives, exact operation bindings
and evidence carry only noncontent random references and scope, never text or
private content hashes. Editing retains versioned private payloads. Atomic
replacement, bounded reads and restrictive file/directory modes support local
storage. No persistent search index is created. The reserved derivatives
subdirectory belongs exclusively to this store. Deletion first writes a tombstone,
then removes every active payload version and owned derivative. Historical refs
survive with derived deleted status. Existing separately stored interview
rationales are inspectable/deletable; deleted rationale text cannot reappear
through its historical reader. Renderer note query caches and draft text are
cleared after deletion. External backups, filesystem recovery and previously
shared copies are explicitly outside secure-erasure claims.

The standalone history projection delegates each accepted result to the existing
classification-aware public evidence projection. It excludes all private note/
rationale references, their hashes, revision/operation identities, inputs and goal
text across the supplied history. It preserves physical result identities and
computes a separate projection digest. It is explicitly an evidence projection,
not the WP-039 history-inclusive portable archive or a sharing-consent capability.

Separate author inspection covers selected context and scope, request/reply
binding, bounded pages and expression mappings, immutable model definitions,
point-only assumptions, goal/physics separation, private version ownership,
old-note/rationale/derived canaries, deletion/replay, stale mutation and lost-reply
recovery. Packaged keyboard coverage exercises persistence, cross-view goal
observation, old private versions, historical read-only editing and deletion.
Validation route: **solo-validated; agent review deferred**. Actual command
outcomes and native/platform limitations are reported in the delivery PR.
