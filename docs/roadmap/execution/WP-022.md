## Implementation and separate inspection

The `overview` schema-1 contract is generated from Python. Three named, bounded
preload methods read observations, compare ephemeral targets and prepare chart
approximations; main validates sender/frame, schemas, selected context, reply
identity, model and time. Query equality is structural, independent of object
field order. Requests keep the existing 16 KiB bound and replies stay under 1 MiB.
No new path, SQL, executable data, mutation authority, dependency or store schema
is introduced. Frozen locks are unchanged.

The Python projection reads the revision's accepted closure, including definitions,
measurements, reconciled accounts, typed findings, source/license revisions,
assumptions and full trace dependencies. Generic pages contain at most 25 items
and 800,000 serialized item bytes; trace pages contain at most 10 vertices under
the existing 900,000-byte trace bound. Cursors bind the complete context, scope,
collection, selection and evidence identity. Oversized individual trace vertices
fail visibly under the existing engine limit; no new chunking protocol is claimed.
Rooted traversal opens the selected calculation first and preserves feedback edges
and all transitive dependencies, including dependencies at other scopes.

The renderer shows up to eight selected indicators (four initially), exact values,
units, scope/time/denominator, all seven coverage meanings and named diagnostics.
Green means the named condition is met; orange is a named uncertainty warning;
red is a named physical/policy/institutional diagnostic; gray retains its distinct
coverage reason. Neutral measurements have no assumed positive direction. Player
target observations cannot recolor engine diagnostics. Findings across scopes
remain visible regardless of selected indicators. Distribution tables retain exact
values; Recharts uses explicitly labeled approximate display values for matching
named/procedure/unit/time/version definitions and never infers a spatial total,
ranking or cross-scope conversion. Unknowns never become zeroes.

Shared inspectors expose conditions/owners/provenance, definitions/inputs and
threshold provenance, exact account balances, findings, sources, assumptions,
pageable calculations, feedback edges and dependency navigation. Qualitative
commitments reuse the existing original-wording presentation instead of exposing
serialized metadata. Retained goals/policies remain separate from these commitments.
Optional AI explanation absence and unmodeled/excluded effects are explicit.
No source link or embedded text loads remote resources.

Visibility choices and exploratory targets are session/context-local presentation
state. Accepted goals remain revision-owned and inspectable. Target comparisons
run the existing post-evaluation observer against retained input/model data with
no numerical callback or persistence. Changing a target preserves physical output,
accounts, accepted report, revision record and branch sequence. Save/export of
presentation preferences is outside this package.

The separate author inspection checked query/cursor bindings, scope filtering
before pagination, source and private-rationale isolation, exact decimal display,
status meanings, target independence, and model-free historical inspection. It
caught and corrected field-order-sensitive reply binding, target findings affecting
warning colors, and selected calculations occurring on a later trace page. Fixed
tuple validation now supports retained feedback edges while rejecting malformed
endpoints. This is author inspection, not independent agent review.
