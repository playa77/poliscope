## Runtime changes and invariants

WorldGraph builds one immutable endpoint adjacency index from its validated
snapshot. `related` reparses only incident rows, preserves source order and kind
filters, returns detached DTOs and counts self-edges once. Replacing relationships
constructs a new index. Derived indexes stay outside dataclass fields so existing
canonical world serialization/equality are unchanged. Deep copies can reuse the
immutable snapshot.

EvaluationCache retains complete validated result bytes under both entry-count
and byte quotas, evicts least recently used entries and supports explicit clear.
Oversized results are computed completely and returned without caching. All input,
model, review, numeric and realization identity preparation still runs before a
hit. Results stay detached. The byte quota bounds serialized results, not registry
objects, Python overhead or combined application RSS. Accepted revision evidence
remains separately retained.
