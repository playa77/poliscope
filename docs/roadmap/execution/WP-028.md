## Implementation and inspection

Python owns discovery, filtering and deterministic, query/catalog/context-bound
pagination. The pinned release supplies twelve authored questions plus 24 civic
source rounds, all complete alternatives, twelve domain labels and the branch
and source directories. Four provenance question records are excluded. Domain/
branch tags use explicit inventory amendment links; absent mappings stay visible
as unresolved, and those questions still open through the cross-domain interview.
Historical adoption is shown independently of the player's selected ID. Filters
include source, scope, selected/unanswered/proposed status, modeling/evidence and
open issues; full-text search includes the alternatives, not just summaries.

New commitments archive the complete question/option definitions and location
tags in the immutable revision. Legacy commitments recover their complete option
sets from the originating revision's saved alternatives, without substituting
live catalog text. Proposals retain their original wording and supersession refs.
The label-value bound widens from 4,096 to 131,072 characters to accommodate these
complete source archives; generated embedded schemas reflect this compatible
widening. The 1 MiB IPC frame bound remains unchanged, atlas pages stop at five
items/700 KB, and source text uses 12,000-character pages with pinned revision,
attribution and license text. Oversized individual future records fail explicitly.
Source lookup reads the immutable bundled release, not a remote live document.

Named atlas/source IPC validates both request and response and authorizes the
exact selected context. Interview queries optionally name a specific question;
preview/apply still reconstruct host-owned changes, validate ownership and stale
heads, retain private rationale separately and never activate source prose as a
numerical model. Existing synthetic labels and condition editing are preserved.
The renderer holds only temporary filters/navigation. Query keys include full
revision, scope, model/catalog/runtime versions, time and filters; late replies
cannot overwrite another selection. Filters persist while moving to history or
interviews. Semantic controls, result counts, loading/error/empty states, original
wording, source/license inspection and keyboard focus transfer are provided.

The separate author inspection covered new/changed engine and desktop source,
generated contracts, corpus closure, immutable history, context grants, bounded
frames, text-only rendering and acceptance tests. It found unmapped source
questions could not open for preview; the explicit unresolved-domain route now
handles all 24 civic rounds. It also caught duplicate proposal IDs during repeated
proposal edits; archive options now use one entry per identity, with historical
revisions retaining previous proposal wording. A regression check restored the
preexisting synthetic decision display label. The packaged keyboard flow found
that navigation could remount the atlas and drop filters; these now live in the
workspace session state. Inspection also bound legacy alternative recovery to a
revision that actually changed the commitment, preventing an unrelated domain's
`player:proposal` operation from truncating its option set. Regression coverage
includes two domains with distinct proposals and a legacy archive.
