## Scope

The owner asked for a complete replacement of the desktop presentation layer,
not a restyle: the renderer was React 19 with one 80-line hand-written
`desktop/renderer/style.css` (green-on-charcoal), 1 827 lines of TSX across
twelve screens, no Tailwind, no component library and no design tokens.

Design-system adoption is a rendering-layer change, so this package is
deliberately ordered foundation first, then screens, with the working tree
building and the regression suite green at every commit.

(several labelled options on one PNG) converged in one round where prose
descriptions had failed three times; prefer it when taste is the open question.

## Delivered

- Tailwind v4 through `@tailwindcss/vite`; `components.json` registers the ReUI
  registry (`@reui` → `https://reui.io/r/{style}/{name}.json`) on the
  `radix-nova` style. Components install as owned source under `components/`.
- Design tokens (`desktop/renderer/style.css`) for the identity, light and dark,
  mapped through `@theme inline`, plus a transitional element layer
  (`.legacy-ui`) so screens that have not migrated already render in the new
  palette instead of keeping the green.
- Inter bundled through `@fontsource-variable/inter`; no runtime font fetch, so
  the app stays offline and the packaged content policy is unchanged.
- Shell components: floating navigation rail (`AppShell`, `NavGroup`, `NavItem`),
  content blocks (`Panel`, `Stat`, `StateBadge`, `EmptyState`, `ErrorNote`,
  `LoadingRows`, `KeyValue`), and `NativeSelect`.
- `src.tsx` owns the active view so navigation lives in the shell; `workspace.tsx`
  keeps every existing contract, focus effect and page-scoped state, and renders
  into the new chrome.
- `@/*` resolves in vite, vitest and tsc (TypeScript 7 removed `baseUrl`; paths
  are configured without it).
