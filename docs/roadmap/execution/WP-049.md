## Implemented parent behavior

The existing provider UI supplies model search/selection, catalog age and capability
constraints, route/privacy/generation controls, key status and selected/reported
identity. Existing immutable grounding supplies explicit collection/scope/task
selection, dependency/source inspection, exact comparisons and bounded structured
parameter proposals. An explicit authored-interview shortcut copies only public wording, original context,
dependencies and references into a displayed local draft; a separate user action
replaces the editable composer. It excludes current commitments, private rationale
and unsaved choices and sends nothing. Editable question starters expose clarification, evidence
explanation, comparison and qualitative alternative tasks without a hidden default
policy or automatic inclusion. Unsupported capabilities remain explicit.

A main-owned retained-turn index now exposes creation time, selected model, status
and original context. Prior turns can be reopened after deliberate new requests;
opening them does not reuse history or relabel their revision. Existing stop,
partial result, exact payload/cumulative disclosure, continuation and durable usage
controls remain in the same workspace. Proposal preview and ordinary Apply retain
the player-only mutation boundary. A completed grounded text reply can explicitly
promote an exact user-selected excerpt, at most 1,024 characters, into an ordinary
qualitative interview alternative. Main binds the original revision/scope, requires
the excerpt to occur in the visible reply, withholds attachment/revoked/incomplete
turns and preserves original starting conditions. Python retains `ai_proposed`,
unverified coverage and request/manifest references with the public excerpt; no
private prompt or whole transcript is promoted. Preview is pure and Apply is an
ordinary separate player action. Stale context cannot apply to another head.
Deletion/cancellation revokes matching pending preview grants; a late preview
cannot resurrect a deleted turn or cancel an unrelated newer draft.

Optional local snapshots retain only explicit user text, visible response text and
bounded original-context/identity/time metadata. They are never automatically saved
or read into a future request. They are main-owned, schema-validated data outside
the civilization database, mode 0600 on Linux, written through a new temporary
file and rename. Capacity, malformed files and oversized replies fail closed
without truncation or silent eviction. At most sixteen snapshots and 32,768 reply
characters. Attachment turns are ineligible: their private derivatives remain
session-only. Reasoning, full tool/provider payloads, artifacts and Apply grants
are absent. Snapshots are inert escaped text after restart, with no key/profile
required and no execution/continuation/Apply controls.

Saved-copy deletion is independent of live turns. Full turn deletion removes saved
text and the existing active owned lineage, retaining public design changes and
noncontent spending/history references. Reports and archives never include these
snapshots; their independent note/rationale inclusion controls are unchanged.
Backups/external artifacts may retain copies; secure erasure is not claimed.
See [workspace behavior and bounds](../../assistant_workspace.md).
