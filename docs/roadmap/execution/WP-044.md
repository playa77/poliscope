## Implementation and separate author inspection

The pure main module constructs the documented OpenRouter and separate compatible
chat bodies, freezes inspected plans and binds capability/context evidence to the
saved profile/endpoint/revision. Unknown or incompatible selected controls reject
with fixed codes. Every configured fallback revalidates; provider-only failover
never adds another model. Optional settings v1 extensions preserve cold reads of
old profiles. The named IPC still provides settings/metadata only; no generation
command, credential reply, extra engine command or automatic network action exists.

The response contract preserves selected and reported actual model/provider,
finish status and known parameter rejections. Its bounded local JSON Schema
subset rejects unknown keywords before construction and refuses invalid,
truncated, filtered, refused or unexpected-model outputs as validated data.
Tool definitions do not execute tools or authorize proposals. Formats include
text, JSON object and strict named schema output; stream/nonstream construction
is ready for the WP-045 lifecycle consumer.

The separate inspection traced the canonical DTOs and generator, settings UI →
existing authorized settings IPC → vault-separated persistence, then pure builder
→ model/parameter/reasoning/context validation → immutable wire request and safe
normalization. It checked that no credential/send capability entered the new
modules, no untrusted schema could fetch or execute code, all unknown controls
reject, every fallback receives the same privacy controls, and no result has an
apply path. It checked the 32 KiB/1 MiB/depth/node limits, explicit unknowns,
source/time requirements and old-profile cold compatibility.

Inspection corrected decimal-ceiling serialization, compatible effort validation
against current official docs, preservation of unrelated reasoning settings when
returning one field to default, and explicit accessible names on selects.
**solo-validated; agent review deferred**. This is author inspection, not an
independent review.

this package does not pretend one universal byte/token conversion is valid.

main library entry points for those consumers; the existing app continues to send
only deliberately requested non-billable metadata. Local schema validation has

and validated player apply action.
