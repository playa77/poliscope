## Limits and next action

The desktop exports all scopes from the selected folder or chosen imported
collection; the typed service can filter result scope while retaining context and
trace closure. CSV contains measurement/state/law/comparison rows, not private note
payloads; private notes/rationale are explicit Markdown opt-ins. Existing stores
have no transcript/attachment payloads. No AI prose is generated. Uncommitted
uncertainty/sensitivity previews are not exported as historical outcomes.

A projection is bounded at 256 MiB and a report at 512 MiB, with <=64 KiB file
writes and a 120s main worker deadline. Killing a worker may leave a hidden staging
file, or a completed file if publication already happened; the UI states the
uncertain-result behavior. It never reports a partial destination as complete.
Windows x64, scientific/nonauthor review and G5/M5 remain unrun. WP-041 migration
and recovery remain separate, not implicitly completed by report export.
