## Scope and acceptance

Run actual facility/path reach against one finite dated slot book, then gate each
explicit provisioning phase claim on its declared full slot prerequisites. A
complete mapping is mandatory; multiple demands require all prerequisites. The
host explicitly declares cross-scope prerequisites; no physical location or route
is inferred from stock scope. Finite slots remain disjoint from the canonical
material/time/land/energy/throughput/entitlement book. No slot/kg conversion is
inferred. Reach can restrict existing access but cannot grant access or erase an
unknown. Unknown reach withholds a complete chain candidate. Denied, disconnected,
nonoperating and short capacity retain different infrastructure evidence.

Preserve prior slot postings and holds exactly once, without treating a prior
commitment as proof of current physical reach. Preserve independent work and all
chain account evidence when a known gate blocks a claim. Input commitments are
not refunded if a subsequent gate fails. Reject mismatched dates, overlapping
pools, unregistered capacity accounts, incomplete/duplicate/unknown mappings,
invalid paths, forged nested DTOs, stale context and foreign runtime identities.
Opaque digest ports bind the request, complete world/membership, units, model,
and runtime identity. Activation separately requires matching declaration reviews.
No serialized resource book is accepted from ports. Common conformance uses real adapters repeatedly and explicit
host reviews; registration alone grants no callbacks or execution permission.

Validation route: frozen installs; independent integer/Fraction slot, material and
time oracles; adversarial/focused and full Python; generated contracts/content;
TypeScript/desktop units/roadmap; readiness/baseline/exact gate manifest;
whitespace and separate author inspection. Independent review remains deferred.

## Limits and next package

This is a bounded host-only static prerequisite adapter. It does not implement
infrastructure operating labor/energy/land, building/repair, lifecycle transitions,
housing or digital service coverage, freight throughput from path slots,
scientific validity, source activation, numerical IPC, durable publication or
parent/cumulative gate acceptance. Earlier counterpart callbacks remain available
only in their own explicit hosts. Five pairs are ready for bounded conformance;
39 remain pending. After merge reassess a bounded DOM-01/09 communication
counterpart against the actual channel interface and available prerequisites.
