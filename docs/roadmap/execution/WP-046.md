## Implementation and separate author inspection

The full parent integrates the prior envelope with a Python-owned classified
projection and a single canonical generated read-only tool. Main retains the
original manifest/store closure; provider calls never supply revision, branch,
file, URL, key or execution authority. Exact next payloads include all calls,
results and prior messages and require fresh review plus a distinct same-turn
spending grant. Three continuation rounds, eight calls and cumulative bytes are
bounded. Revocation is shared across every round. No-tool explanation remains
available when metadata supports the supplied text context.

Compatible proposals are existing editable point assumptions consumed by
registered mechanisms. Real pure engine preview preserves kind/unit/scope/time
metadata; unsupported mechanism/model edits remain unavailable. Player-selected
proposals enter the ordinary evidence candidate path and its stale/idempotent
Apply. Immutable public assumption descriptors retain authored/player/AI origin,
coverage, request identity and manifest digest; later player edits identify their
own origin without rewriting historical receipts. Pending proposals are session
local; transcript persistence is WP-049.
