# Optional assistant workspace

Provider settings supply model discovery, cached catalog timestamps, selected and
reported identity, routing/privacy preferences, key status, generation settings,
capability limits and durable usage. Discovery is provider evidence, not a promise
of model availability. Offline interviews, simulation and reports need no provider.

From an authored interview, **Review this question with optional assistance** opens
its public wording, dependency/source references and original context for local
review. **Use this public question as the editable draft** explicitly replaces the
composer; no private rationale, current commitment or unsaved alternative is copied.
No provider request occurs. Oversized questions remain unavailable for this bounded
shortcut. The exact current request context must still be reviewed before sending.

Each request starts with explicitly entered text. Editable question starters help
clarify an interview, inspect dependency/source evidence, compare explicitly shared
alternatives or propose a qualitative alternative. Select public collections,
scope and task deliberately. The exact payload and immutable original context are
shown before sending. Unknowns remain unknown; no assistant chooses for the player.
Tool continuations require another exact disclosure review and spending reservation.
Stop preserves partial status and honest uncertain exposure. The selected model,
reported model/provider and USD usage remain visible separately.

Retained turns are private session objects. Refresh their list and open a prior
turn to inspect its original branch/revision/scope, even after changing designs or
profiles. Opening it does not copy its contents into a new provider request. At
most sixteen dispatches are retained per session, including continuation rounds.
Deleting a turn removes its whole active lineage and owned derivatives, freeing
those slots; cancellation alone keeps its partial evidence available.

## Optional local text snapshots

Use **Save this text transcript locally** on a finished, incomplete or tool-call
reply to retain explicit user text and visible assistant text with original context,
creation/save times and selected/reported identities. Nothing is saved automatically.
Snapshots are private data in main's `assistant-private/transcripts.json`, outside
the civilization store. They can be read after restarting without a key or profile.
They are escaped text, with no Markdown/HTML/media execution or resource fetching.
They cannot send, continue, run tools or Apply a proposal. No saved snapshot is
consulted when preparing a new request or report/archive export.

The bounded store accepts at most sixteen snapshots and 32,768 characters per
reply; oversized replies are rejected without truncation. Attachment turns are
ineligible so their excerpts/derivatives cannot escape session ownership through a
text snapshot. Artifacts, opaque/visible reasoning, tool payloads, proposal previews
and full provider messages are not persisted. External artifact exports remain an
explicit separate action. Corrupt/unsupported or oversized storage fails visibly;
existing copies are preserved instead of silently replaced or evicted.

**Delete saved text** removes saved copies in that turn's lineage while leaving
active turns available. **Delete this turn, attachments and all active derivatives**
removes active turns and their saved text lineage. Other saved turns, committed
choices and accepted proposals remain. Spending identifiers and unresolved charges
survive. Filesystem backups and explicitly exported external files may retain
copies; deletion does not promise secure erasure.

## Explicit design promotion

For a completed grounded text reply, paste an exact excerpt into **Public
qualitative excerpt**, select a domain, and choose **Preview this excerpt as a
qualitative alternative**. At most 1,024 characters can be promoted. Main verifies
the excerpt against the visible reply, binds its original revision/scope and
preserves starting conditions. Revoked/incomplete/attachment turns cannot use this
path. Python retains only the excerpt, `ai_proposed`, unverified qualitative
coverage and noncontent request/manifest references. The separate ordinary Apply
commits one qualitative choice; no model code or numerical effect is activated.
Deleting the transcript afterward preserves this accepted public choice.

Existing grounded parameter proposals also use ordinary noncommitting evidence preview and the
player's Apply action. The design retains the promoted parameter/value, origin,
coverage and noncontent request/manifest references. It does not retain the private
transcript. A stale proposal cannot apply to another selected head. Transcript
navigation or deletion never grants mutation authority or rolls back accepted
history. Reports/archives retain their existing independent note/rationale
inclusion controls; snapshots are always omitted in this version.
