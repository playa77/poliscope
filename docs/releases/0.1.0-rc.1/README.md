# Poliscope 0.1.0 release candidate 1

Prepared 2026-11-01 from merged WP-055, `8244afb`. This is an unsigned educational
prototype candidate. The application still identifies itself as **0.1.0**; the
`rc.1` label identifies this handoff without changing tested application bytes.
No public release, signing, upload to a release channel or merge is authorized by
preparation. The repository owner decides release authorization separately.

[The inventory](inventory.json) freezes every product, generated schema, catalog,
model, numeric runtime, lock, packaging input, WP-055 acceptance receipt and
retained test report by path, size and SHA-256. Its source commit identifies the
merged baseline; the WP-056 delivery commit versions these guides and tooling.
Run `uv run --frozen python scripts/freeze_release.py --check` to detect changed,
added or removed frozen inputs. It never regenerates or silently blesses drift.
For another candidate use `--output` with a new path, after reviewing affected
checks. The fingerprint is an identity check, not a signature or a scientific
validity certificate.

## Available behavior

Core inquiry works offline without an AI account: editable starting conditions,
twelve-domain interviews, pure previews, explicit Apply, immutable branch history,
accounts and calculation traces, atlas/matrix/world views, timeline experiments,
uncertainty inspection, portable histories and Markdown/CSV reporting. Python is
the sole simulation and SQLite authority. Native installers bundle Python; users
need neither Node nor Python. Windows x64 and Linux x64 are the current targets;
Mac is deferred.

Mechanisms are authored hypothetical numerical/procedural models with explicit
coverage. The source inventory has **453 rows**, **51 partial static rows** and
**zero source-transition activation**. Running an authored transition does not
activate an unsupported empirical source mechanism. Unknown is distinct from
zero. Source choices, personal goals and AI proposals do not become physical laws,
mandatory policy or an overall civilization score. See the frozen
[model review](../../roadmap/execution/WP-055-model-review.json) and
[source review](../../roadmap/execution/society/review.md).
