# Inquiry without an AI account

Install a verified native candidate using [native distribution](native_distribution.md).
Open Poliscope, select a local data folder and create a civilization. Set named
starting conditions that describe your example. Leave questions unanswered when
you lack an assumption; unanswered and unsupported effects are visible model limits.

Record an expectation in a note before changing a choice. Open a domain interview,
read its alternatives and source/coverage information, then preview a choice.
Inspect changes, affected accounts, units, group/scope, time and model identity.
Cancel to discard the preview, or choose Apply explicitly to save a revision.
A preview, target or assistant proposal never commits a change on its own.

Inspect the saved account and calculation trace. Distinguish a source statement,
your assumption, an authored mechanism, a retained measurement and an AI explanation.
A quantity outside supported precision is rejected with representability diagnostics;
there is no hidden negative clamp or rounding to make an account balance. Declared
quantum/residual rules retain their evidence. Missing values remain unavailable.

Fork a saved revision before trying a different arrangement. Compare compatible
units, scopes, time bases and models; incompatible quantities have no numeric delta.
Changing a target adds an observation rather than optimizing or redesigning society.
The atlas, matrix list and world views inspect the same saved context. A blank edge
is not evidence of independence. Timeline experiments use explicit future policy
adoption; a fork of the past is a separate counterfactual. Pausing/cancelling retains
only complete confirmed boundaries. Replaying needs the pinned execution runtime;
stored history can remain readable when execution is unavailable.

For uncertainty, declare a point, range or supported probability law. A range is
not automatically a midpoint or a probability distribution. Sensitivity variants
and capacity bounds carry method assumptions and explicit unsupported coverage.
None selects a universal winner. Scientific conclusions require evidence beyond
these hypothetical examples.

In **Portable history**, keep **Include saved results and traces** selected for
an evidence-complete archive. **Export Markdown inquiry report** records the
question, saved inputs, results and limits. **Export typed CSV** retains exact
quantity strings, units, identities, declared distributions and time series.
Text cells carry one leading apostrophe for spreadsheet safety; remove exactly
one when decoding text programmatically. Compare only compatible measurements.
Private notes/rationale require explicit opt-in and cover all retained revisions.
Keys, key blobs, transcripts and attachments are excluded from these exports.
Public simulation inputs and goal questions remain included; inspect before sharing.

Use keyboard Tab/Shift+Tab and ordinary button activation. Statuses include text;
matrices have list/table alternatives. [Accessibility evidence](accessibility_usability.md)
records the tested paths and remaining human review limits. Report an inaccessible
control with its visible label and action, without sharing a private save.

An optional assistant requires your own provider key. Read [provider settings](provider_settings.md)
before sending anything. Sharing is reviewed per dispatch, tool retrieval stays
within the approved context and spending is reserved before billable dispatches,
including continuations. Removing a key or deleting a conversation does not delete
civilization history. Offline inquiry remains available after network failure.
