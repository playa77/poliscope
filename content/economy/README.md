# Economy research coverage

[coverage-v1.json](coverage-v1.json) reconciles all four economy branches, twelve
leaves and every pinned source/system decision. It records source alternatives
as provenance, never selects them or grants them numerical behavior. The strict
content validator checks source revision/digest, exact rows/titles/references,
known model bindings and scope/availability dispositions.

Only generic declared goods access and canonical shared time have partial,
hypothetical static support. Funding is expenditure, not payment settlement.
Ownership law, markets, prices, wealth dynamics, inheritance, automation and
source policy effects remain unsupported. All transitions remain unavailable.
These standalone research records do not change the immutable production release.
