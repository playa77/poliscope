# Interview boundary v1

Original synthetic context templates use the shared pack Definition contract.
They are hypothetical qualitative content, not the society corpus or a numerical
model. Templates are versioned in `interviews.py`; wording changes must change the
definition version. Every recorded alternative archives the original question,
option, readable card, scope, dependencies and coverage in typed design content.
The selected commitment is a decision entity/value, never an executable policy.
Existing numerical graphs are preserved; only matching registered runtimes can
preview/apply. Templates may not register code or social coefficients.

`workspace` dispatches named read/preview/apply calls. Main grants one selected
context and retains the exact edit, candidate and random operation identity.
Renderer cannot submit arbitrary changes, paths or operation IDs. Apply reconstructs
and revalidates the exact preview; stale heads return current state without a
mutation. Same-session uncertain retries retain the mutation identity. After
process loss, reopen confirmed history instead of inferring completion from a draft.

Private rationale files live only in the selected store's `private-interviews/`
directory. The file name hashes its private reference; payload binds private
classification, original context and text. New files use restricted permissions,
fsynced staging and atomic non-overwriting links before committing the revision.
A crash can leave a private staged/orphan note, but cannot publish a revision with
an unwritten note. Same-payload retries reuse the file; different payloads cannot
replace it. References bind a salted payload identity; text is absent from revision
snapshots, alternatives, accepted evidence and durable operation bindings. Local
file deletion leaves noncontent refs in history. Portable sharing, private-payload
management/deletion UI and notes indexing retain WP-031/WP-039; a raw filesystem
copy is not a classified export. Storage schema 1 is unchanged.

Pure previews do not write rationale files or accepted history. Cancel and defer
only clear the main/session candidate. Typed conditions preserve exact decimal
strings and unknown values; they do not calculate social effects or populate goals.
