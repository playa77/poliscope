# Scoped equal-member decision preview

`evaluate_governance(request, graph=..., mechanisms=..., units=...)` accepts a
complete trusted host snapshot. It validates direct jurisdiction and the exact
proposal/target through the production WP-013 policy resolver. Overlapping
bindings retain named findings; file or identifier order never chooses authority.
An explicit select rule must select the proposal being considered. Composition
and bounds remain policy services, outside this ballot procedure.

The host declares canonical eligible cohort/institution IDs, one equal vote per
member, quorum, and strict majority or unanimity. Duplicate/ineligible ballots
are rejected. Abstentions count toward quorum and the approval denominator;
missing members do not. Ties reject, missing quorum has a separate outcome, and
unknown ballots/rules/inputs give a null outcome. These assumptions are authored
hypothetical procedures, not empirical legitimacy claims or population weighting.
The host must validate disjoint representation, delegate mandates and eligibility;
registry existence alone does not establish those institutional facts.

Named administrative claims must be positive participation work in the selected
scope with registered population-cohort claimants. Their actual time is allocated
by DOM-02's existing holder/period/dimension checks and shared finite allocator.
Care, training and other activities compete in the declared full claim order.
Every required administrative claim must be fully fulfilled before a decision
can complete; a partial hour allocation does not produce a fractional decision.
Earlier fulfillment remains inspectable and is not deducted again.

Results retain the detached full request, policy findings/rules/provenance and
complete economy account/claim/posting evidence. Allocation batches represent
private demand previews, including for rejected or capacity-blocked proposals.
No result is a revision candidate or authorization to adopt a policy, spend time,
publish or execute institutional action. There is no store, clock, callback,
renderer/IPC, default civic answer, global legitimacy score or transition here.
