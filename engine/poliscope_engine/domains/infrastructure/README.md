# Infrastructure: finite facility reach

`evaluate_infrastructure` is a host-only pure static interface. Canonical assets,
locations, directed connectivity and explicit paths share one dated facility-slot
account book. A demand consumes the selected facility plus every path link once,
using the shared allocator and an explicit host procedure/order. Local demand has
an empty path; a disconnected empty path retains the unmet claim. An omitted path
to a connected remote destination rejects rather than selecting a route.

Planned, offline and retired assets block new commitments. Unknown availability
or access withholds all competing allocation. Access denial is independent of
physical connectivity. Prior postings and reservations survive; results distinguish
prior commitments, additional allocation and unmet demand. Lifecycle declarations
are inputs, never transitions. Retained earlier commitments are not refunded when
an asset's availability changes. Prior commitments do not prove prior reach.

This interface does not create supplies or deliver treatment/education, operate a
freight network, quantify housing coverage or commission/build/repair assets.
Operating labor/energy/land, authority, lifecycle/resource coupling, digital
bandwidth, source coverage and authored previews require separate work. No model,
publication, numerical IPC or parent acceptance is activated.

Host-only `exploration.interview` offers explicit declared and reversed queues,
without a selected default. `preview` binds the entire request, world, unit registry
and implementation identity; only claim order changes. Reports are detached pure
candidates, with no database or numerical IPC publication. Standalone source gaps
are reconciled by `coverage.validate_coverage`; partial transportation coverage is
facility-slot reach, not freight movement or transportation service delivery.

The host-only `provisioning.infrastructure` counterpart now invokes this actual
finite evaluator to gate explicit production/freight/storage/use prerequisites.
A complete phase-claim mapping is required. Full slot commitment and current
reach are prerequisites, never a numerical freight-throughput conversion. The
facility/path book remains disjoint; unknown reach withholds the chain candidate,
and blocked reach preserves its cause and earlier independent commitments.
This bounded static integration does not implement operating resources,
construction, repairs, lifecycle transitions or parent acceptance.

The private economy/infrastructure counterpart evaluates this actual facility and
path interface, requiring full declared reach for mapped economic claims. Slot
commitments remain inspectable and disjoint from finite economy time/stock/rights.
It restricts access without inventing throughput conversions, operating-resource
or lifecycle effects; unknown reach withholds the complete candidate. See the
[package record](../../../../docs/roadmap/execution/WP-032-counterparts-economy-infrastructure.md).
