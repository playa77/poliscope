# Communication prerequisites

`evaluate_communication` is a pure host-only adapter over canonical assets,
institutions, directed information-channel relationships and one finite account
book. Explicit recorded/available, publication/receipt access, disclosure,
availability and delay inputs gate message-slot commitments. Optional named
verification consumes a separate finite slot atomically. Evidence retains the
complete request, staged postings, holds and unmet quantities.

All arithmetic belongs to the existing allocator/account book. Output indicates
capacity readiness only: no message delivery, verification result, truth/trust
score, wall-clock timing or policy enforcement. Delay is a retained declaration,
not an executed transition. Message bodies and application private payloads are
outside this contract. No network access, IPC activation or mutable domain state.
See the execution record for remaining parent acceptance and actual consumers.
